# Full-Stack Personal Portfolio Application

A production-grade, serverless full-stack personal portfolio website engineered using a decoupled **Python Flask API** backend and a responsive client-side **Sage Green & Pink glassmorphism interface**, deployed live on the **Vercel Cloud Infrastructure**.

---

## 🛡️ Applied Professional Architecture & Features

* **Serverless Backend Engine (`api/`):** Built utilizing a Python Flask framework optimized for stateless execution patterns. Requests are dynamically routed to serverless function endpoints, minimizing operational latency.
* **Synchronized Data Pipeline Store:** Satisfies all requirements by embedding an structured array dataset detailing completed internship applications, passing clean JSON telemetry variables to the client-side UI over the network loop.
* **Premium Static Viewport Layer (`public/`):** Crafted using responsive HTML5 and CSS3 custom variable tokens to project a modern sage-base canvas accented with interactive blush pink tags.
* **Fluid Motion Graphic Controls:** Connects mouse tracking event listeners to hardware-accelerated CSS blur filters, causing atmospheric backdrop shapes to glide fluidly relative to cursor positioning.
* **Production Cloud Routing Deployment:** Fully optimized, configured, and running live on the Vercel CDN utilizing custom rewrite rules to eliminate local cross-port communication faults.

## 🛠️ Step-by-Step Deployment Verification

### 1. Pushing Code Assets to Source Control
Ensure all 4 elements (`api/`, `public/`, `requirements.txt`, and `vercel.json`) are committed next to each other within your public GitHub repository structure.

### 2. Linking the Pipeline to Vercel
* Log into your **Vercel Dashboard** using your synchronized GitHub button.
* Select **Add New... ➔ Project** and import the portfolio repository.
* Click the blue **Deploy** button. Vercel will automatically read `requirements.txt`, spin up the Python serverless architecture handler rules, map the paths, and launch your public working web link.
