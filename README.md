# # High-End Full-Stack Personal Portfolio Website

A production-grade, decoupled full-stack personal portfolio application engineered using a **Node.js/Express architecture**, a dynamic cloud-hosted **MongoDB cluster**, and a responsive **Sage Green & Pink glassmorphism interface** deployed live via **Vercel**.

## 🚀 Applied Professional Stack & Features

* **Static UI Layer (`public/`):** Crafted using responsive HTML5 and CSS3 custom variable tokens to project a modern sage-base layout engine accented with reactive blush pink layers.
* **Fluid Motion Graphic Engine:** Utilizes matrix coordinate tracking listeners linked to hardware-accelerated CSS blur filters, causing layout shapes to glide fluidly relative to cursor positioning.
* **Serverless Backend Engine (`api/`):** Avoids massive local deployment constraints by deploying a clean Node.js endpoint module mapping system requests cleanly to remote instances.
* **Distributed Cloud Database Layer:** Satisfies all persistence criteria by integrating the official native `mongodb` client driver to stream project tracking records dynamically out of an encrypted database cluster.
* **Production Cloud Deployment:** Fully optimized, configured, and running live on the **Vercel Cloud Network Platform** utilizing advanced automated file routing structures.
